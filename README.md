# java-se-http-server
Учебный проект, выполненный в рамках курса Udemy (Java SE Fundamentals – HTTP Server). Цель — закрепить основы Java SE через практику: создание простого HTTP‑сервера, работа с сокетами, обработка запросов и формирование ответов.
Features
Socket programming (TCP connections)

HTTP request parsing (HTTP/1.1 basics)

Response generation (headers, body, status codes)

Logging and error handling

Unit testing (JUnit, Mockito)

Build automation (Maven)

 Lessons Learned
Object-Oriented Programming (encapsulation, inheritance, polymorphism)

Exception handling and robust code design

Collections and data structures in practice

Multithreading basics for handling multiple requests

JDBC fundamentals for database connectivity

Debugging and testing workflow

Technologies
Java SE · OOP · Sockets · HTTP Protocol · Backend Architecture · Multithreading · JDBC · Maven · JUnit · Mockito · Debugging & Testing
